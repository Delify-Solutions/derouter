## 7. Cross-phase security & data-integrity (apply throughout)

- [x] 7.1 Never leak key existence on public routes — unknown/deactivated keys return 404, not 401/403.
- [x] 7.2 Redact `authorization`, `x-api-key`, `cookie`, `token`, `api-key` (case-insensitive contains) from stored request headers before persisting in `requestDetails`.
- [x] 7.3 Mask keys `sk-…****last4` (>=10 chars) or `****` (<10) in every UI display (usage, public, admin lists).
- [x] 7.4 `requestedModel` (combo name) is the client-visible model; resolved provider/model and provider identity never shown to key holders (admin drawer may show `resolvedModel` as "via").
- [x] 7.5 rusqlite transactions always end with explicit `tx.commit()?`; never rely on drop for success; never double-call `transaction()()`.
- [x] 7.6 No real secrets in code — secrets read from env/DB at runtime; the existing `.env` stays gitignored; the Rust port's `.env.example` documents names without values.
- [x] 7.7 Existing Node/JS files under `src/`, `open-sse/`, `cli/` are untouched — all work is additive under `derouter-rs/`.
